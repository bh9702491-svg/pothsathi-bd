# পথসাথী BD (PothSathi BD)

**সহায়তা খুঁজুন • দক্ষতা গড়ুন • ভবিষ্যৎ সাজান**

বাংলাদেশের মানুষের জন্য বাংলা-ভিত্তিক অ্যান্ড্রয়েড অ্যাপ: সরকারি সেবার গাইড, দায়িত্বপ্রাপ্ত অফিসের তথ্য, ভাতা ও সুবিধা, এবং ক্যারিয়ার রোডম্যাপ।

> ⚠️ **তথ্যের সততা:** অ্যাপে কোনো অফিস, ঠিকানা, ফোন, ফি বা কাগজপত্রের তথ্য আন্দাজে বসানো হয় না। সরকারি সূত্র থেকে যাচাই না হওয়া পর্যন্ত সব তথ্য "যাচাই প্রয়োজন" অবস্থায় থাকে।

## বর্তমান অবস্থা: সংস্করণ 0.1 (ভিত্তি)

দেখুন `PROGRESS.md`।

## প্রযুক্তি (সব বিনামূল্যে)
Flutter + Dart, SQLite (sqflite), GitHub Actions (ফ্রি APK বিল্ড)।

## কীভাবে APK বানাবেন (পিসিতে কিছু ইনস্টল ছাড়া)

১. github.com-এ বিনামূল্যে অ্যাকাউন্ট খুলুন।
২. **New repository** চাপুন। নাম দিন `pothsathi-bd`। **Public** বেছে নিন (Public রিপোতে বিল্ড-মিনিট সীমাহীন ফ্রি)। Create করুন।
৩. এই ZIP আনজিপ করুন। রিপোর পাতায় **uploading an existing file** লিংকে চাপুন এবং আনজিপ করা ফোল্ডারের **ভেতরের সব ফাইল ও ফোল্ডার** টেনে ছেড়ে দিন।
   - গুরুত্বপূর্ণ: `.github` ফোল্ডারটি (লুকানো ফোল্ডার) অবশ্যই যেন আপলোড হয়। Windows-এ File Explorer-এর View > Show > Hidden items চালু করুন।
৪. **Commit changes** চাপুন।
৫. উপরের **Actions** ট্যাবে যান। "Build APK" চলতে থাকবে (৫–১০ মিনিট)। সবুজ টিক এলে ওই রানে ক্লিক করে নিচে **Artifacts > pothsathi-bd-apk** ডাউনলোড করুন।
৬. ZIP খুলে `app-release.apk` ফোনে নিন এবং ইনস্টল করুন (ফোনে "Unknown sources" অনুমতি লাগবে)।

লাল ❌ এলে রানে ক্লিক করে ত্রুটির লগ কপি করে আমাকে দিন; আমি ঠিক করে দেব।

## ফোল্ডার কাঠামো
```
assets/db/schema.sql         ডাটাবেস স্কিমা (১৭টি টেবিল)
assets/db/seed_services.sql  ৮টি সেবার নাম (শুধু নাম, কোনো অফিস/ফি নেই)
lib/main.dart                অ্যাপের শুরু
lib/core/theme.dart          নেভি + টিল Material 3 থিম
lib/core/db/                 SQLite সংযোগ
lib/features/home/           হোম স্ক্রিন
test/                        অটোমেটিক টেস্ট
docs/verify_db.py            ডাটাবেস যাচাই স্ক্রিপ্ট
.github/workflows/           ফ্রি APK বিল্ড
```

## পরিচিত সীমাবদ্ধতা
- Release APK ডিবাগ কী দিয়ে সাইন হয়; পরীক্ষার জন্য ঠিক আছে, Play Store-এর জন্য নিজস্ব keystore লাগবে।
- `android/` ফোল্ডার সংরক্ষিত নয়; প্রতিবার বিল্ডের সময় তৈরি হয়।
